# نظامكم — كما تريدونه

صفحة استكشاف يعبّيها **مدير الشركة** من الصفر، ويصدّر جوابه ملفاً يرسله للمطوّر.
منها يُبنى النظام الداخلي كله: الأقسام والناس، الزبائن، المال، والعمل اليومي.

## كيف تُستخدم

1. أرسل رابط الصفحة للمدير.
2. يفتحها على جواله أو حاسوبه، ويجيب بالوتيرة التي تناسبه — **كل شيء يُحفظ على جهازه تلقائياً**، ويستطيع الرجوع في أي وقت.
3. في آخر الصفحة يضغط **«صدّر الأجوبة»** فينزل ملفان:
   - `اجوبة-المدير-<تاريخ>.md` — نص مقروء
   - `اجوبة-المدير-<تاريخ>.json` — للمطوّر
4. يرسلهما على تيليغرام.

**لا يُرسل شيء من الصفحة إلى أي خادم.** لا تتبّع، لا تسجيل دخول، لا قاعدة بيانات. الأجوبة على جهاز المدير حتى يصدّرها بنفسه.

## للمطوّر

- `index.html` — المحرّك (عرض الأسئلة، الحفظ المحلي، الشروط، التصدير/الاستيراد).
- `questions.js` — بنك الأسئلة. عدّله ليتغيّر المحتوى بلا لمس المحرّك.
- رابط مباشر إلى الأسئلة بلا صفحة ترحيب: أضف `#start` للرابط.
- لاستعادة أجوبة مصدَّرة ومراجعتها داخل الصفحة: رابط «استيراد ملف أجوبة» في أسفل الصفحة.

### صيغة السؤال في `questions.js`

```js
{
  id: "org.departments",            // فريد، بالإنجليزية
  type: "single" | "multi" | "yesno" | "text" | "textarea" | "number" | "table",
  label: "نص السؤال",
  help: "توضيح اختياري",
  example: "مثال ملموس على الجواب",
  required: true,
  options: [ { value: "sales", label: "المبيعات", hint: "شرح سطر" } ],   // single/multi
  allowOther: true,
  columns: [ { key: "name", label: "الاسم", type: "text", placeholder: "…" } ], // table
  minRows: 1,
  showIf: { q: "lines.what", has: "channels" }                                // شرط الظهور
}
```
